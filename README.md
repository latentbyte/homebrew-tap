# Latent Byte Homebrew tap

```sh
brew install latentbyte/tap/lbcat
brew install latentbyte/tap/zmenu
```

| Formula | What it is                                                                                            |
| ------- | ----------------------------------------------------------------------------------------------------- |
| `lbcat` | Browser Control CLI, daemon, and native host for [LBcat](https://github.com/latentbyte/lbcat) (macOS) |
| `zmenu` | Fast native fuzzy menu for macOS, a dmenu alternative ([zmenu](https://github.com/hamidzr/zmenu))     |

Formulas are generated by each project's release script. Do not edit them by hand.
